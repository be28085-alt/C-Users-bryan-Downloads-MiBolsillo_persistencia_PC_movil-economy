MiBolsillo - entrega de codigo completo corregido

Contenido
- Proyecto completo basado en la ultima carpeta economy(2).zip compartida.
- Versiones web de escritorio y movil, paginas de entrada, estilos, scripts y modulos.
- Logica de finanzas personales y de negocio, servicios, dominios, almacenamiento, migraciones, exportacion, graficos y pruebas.
- Archivos de la aplicacion Qt/C++ incluidos en el proyecto original.

Correcciones integradas en esta entrega
1. La utilidad obtenerHistorialMensualReal ahora interpreta correctamente el formato YYYY-MM que devuelve el modulo de fechas y tambien admite el formato objeto de la version clasica.
2. Se conserva la proteccion contra envios repetidos de movimientos en los controladores de PC y movil.
3. Se mantienen los parametros de version de scripts para evitar que el navegador reutilice archivos antiguos en cache.

Verificaciones ejecutadas
- node --check sobre todos los archivos JavaScript del proyecto: correcto.
- node test_shared.js: OK.
- node test_dates.js: OK (agrupacion mensual, ingresos, gastos, fechas invalidas y lista vacia).

Importante
Estas comprobaciones validan sintaxis y logica automatizable en Node. No equivalen a una prueba E2E en un navegador real ni validan la conexion con servicios externos o la compilacion Qt en el equipo local. Se recomienda abrir esta carpeta completa en VS Code y probar los flujos de PC y movil con Live Server.

Inicio
1. Descomprimir el ZIP.
2. Abrir la carpeta economy en Visual Studio Code.
3. Ejecutar index.html con Live Server.
4. Elegir la interfaz PC o movil desde la pantalla inicial.
